# 等风 ERP 导出任务中心

沿用等风 ERP 蓝色顶栏、紧凑筛选与表格布局的静态交互原型。入口为 index.html，可直接打开。

包含订单列表勾选导出、创建任务、模拟排队及处理、任务筛选与分页、详情、取消、重新导出、文件清理、权限视图和示例文件下载。任务保存在当前浏览器本地存储中。

本项目使用虚构订单与人员。下载文件为示例，后台处理及权限切换均为界面演示；生产环境必须由服务端实现任务队列、租户隔离、完整数据及字段权限检查和私有文件下载鉴权。公开仓库不包含真实ERP业务数据、账户凭据或后台接口。

示例任务日期为2026年11月2日，新增任务使用北京时间。

图标使用 Lucide，许可证见 assets/lucide-LICENSE。
